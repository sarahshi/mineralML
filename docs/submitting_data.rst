===============
Submitting data
===============

We welcome the submission of high-quality EPMA mineral analyses that can continue to shape the training dataset. We are particularly interested in extending mineralML to metamorphic and ore systems, and particularly welcome collaboration on this front. You can email `Sarah Shi <mailto:sarahshi@berkeley.edu>`_, or post an enhancement request or report of a bug on the issue page of the `mineralML GitHub repository <https://github.com/SarahShi/mineralML>`_.
